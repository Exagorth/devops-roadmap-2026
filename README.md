# DevOps Roadmap 2026 – Partidos de Fútbol

Plan intensivo de aprendizaje **Sysadmin / DevOps Junior**  
**Octubre 2026 → Diciembre 2026 / Enero 2027**

## Objetivo
Convertirme en un perfil sólido y empleable de Sysadmin/DevOps Junior, con experiencia práctica demostrable.

## Proyecto vehículo
App para organizar partidos de fútbol entre amigos (enfoque WhatsApp-first).  
Usaremos este proyecto para aplicar todo lo que aprendamos: Linux, Docker, CI/CD, Cloud e infraestructura como código.

## Stack que vamos a dominar
- **Linux**: Arch (diario) + Ubuntu Server
- **Bash** scripting
- **Docker** + Docker Compose
- **GitHub Actions** (CI/CD)
- **AWS** (free tier)
- **Terraform** (introducción a IaC)
- Observabilidad básica (logs + métricas)

## Roadmap de alto nivel
- [x] Setup inicial (Arch + repositorio)

- [ ] Docker + Compose

- [ ] Observabilidad + pulido del proyecto
